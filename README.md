# 🔌 LotsOff — Отключение лотов по категориям

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Массовое отключение (деактивация) и включение лотов по категориям/подкатегориям FunPay
прямо из Telegram-меню Кардинала.

> ⏰ Нужен авто-выкл по часам? Смотрите плагин-компаньон:
> **[FPC-LotsSchedule — Расписание лотов («Ночной режим»)](https://github.com/yungspiderq/FPC-LotsSchedule)**

## Возможности

- 🎮 **Меню категорий** — все игровые категории FunPay с вашими подкатегориями.
- ⭐ **Избранные категории** — добавьте категорию в избранное, и она всегда будет
  **первой в списке** (отмечается значком ★).
- 🔴 **Отключение в 1 клик** — отдельной подкатегории или сразу всей категории (игры).
  Статусы 🔴/🟢 в меню обновляются **сразу после нажатия** — никуда переходить не нужно.
- 🟢 **Включение обратно** — так же в 1 клик, поодиночке или «включить ВСЕ».
- ✅ **Сообщение о завершении** — когда плагин закончил выключать/включать лоты,
  в чат приходит сообщение **«Категория «Dota 2» выключена»** (или «включена») + статистика:
  всего лотов / выключено / уже были выключены / ошибок.
  Придёт даже если тип уведомлений «Деактивация лотов» выключен (и без дубля, если включён).
- 🛡 **Хранитель** — удерживает лоты отключенных категорий выключенными:
  - перехватывает **автовосстановление (autoRestore)** самого Кардинала — он не будет
    включать лоты в отключенных вами категориях;
  - периодически (по умолчанию раз в 60 сек., настраивается) проверяет отключенные
    категории и снова гасит лоты, если их кто-то включил (вручную на сайте и т.п.).
- 📋 Список отключенных категорий со статусами.
- 💾 Настройки сохраняются в `storage/plugins/lots_off/settings.json` и переживают рестарт.

## Установка

### 1. Установите FunPay Cardinal (если ещё не установлен)

```bash
wget https://raw.githubusercontent.com/sidor0912/FunPayCardinal/main/install-fpc.sh -O install-fpc.sh
bash install-fpc.sh
```

Скрипт спросит имя пользователя (например `fpc`), установит Python и зависимости,
склонирует Кардинала и настроит systemd-сервис. Затем пройдите первичную настройку
(golden_key, Telegram-бот) по шагам скрипта.

### 2. Установите плагин

**Способ 1 — через Telegram (проще всего):**
1. Скачайте файл [`lots_off_by_category.py`](https://github.com/yungspiderq/FPC-LotsOff/raw/main/lots_off_by_category.py).
2. Отправьте файл вашему боту Кардинала (или перешлите его).
3. В ПУ: `🔌 Плагины` → `➕ Добавить плагин`.

**Способ 2 — вручную:**

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-LotsOff/main/lots_off_by_category.py -O plugins/lots_off_by_category.py
sudo systemctl restart FunPayCardinal@fpc
```

## Использование

1. В Telegram отправьте боту команду **`/lotsoff`**
   (или: `⚙️ Настройки` → `🔌 Плагины` → плагин → `⚙️ Настройки`).
2. **🎮 Категории** → выберите игру → нажмите на подкатегорию (🟢), чтобы отключить
   её лоты, либо «🔴 Отключить всю категорию». Статус сменится на 🔴 моментально.
3. **⭐ В избранное** — на странице категории добавьте её в избранное: она поднимется
   в самый верх общего списка категорий (отмечается ★).
4. Лоты деактивируются, по завершении придёт сообщение «Категория ... выключена».
   Категория попадает в **📋 Отключенные** — теперь хранитель не даст лотам включиться.
5. Чтобы включить лоты обратно — нажмите на 🔴 подкатегорию, либо зайдите в
   «📋 Отключенные» и нажмите на категорию, либо «🟢 Включить ВСЕ лоты».

### Главное меню

| Кнопка | Действие |
|---|---|
| 🎮 Категории | Список категорий FunPay (★ избранные — первыми) → подкатегории с переключателями |
| 📋 Отключенные (N) | Список удерживаемых выключенными подкатегорий |
| 🛡 Хранитель: ВКЛ/ВЫКЛ | Включить/выключить фоновую проверку |
| ⏱ Интервал: 60с | Интервал проверки хранителя (30–3600 сек.) |
| 🟢 Включить ВСЕ лоты | Включить лоты во всех отключенных категориях |

### Страница категории

| Кнопка | Действие |
|---|---|
| ⭐ В избранное / ☆ Убрать из избранного | Закрепить категорию в начале общего списка |
| 🔴 Отключить всю категорию / 🟢 Включить всю | Массовое переключение всех подкатегорий |
| 🟢/🔴 Подкатегория | Переключить лоты одной подкатегории |

Статусы: 🟢 — лоты включены, 🔴 — отключены и удерживаются,
🟡 — часть подкатегорий категории отключена, ★ — категория в избранном.

## Важно знать

- **Автовосстановление Кардинала** (`autoRestore`) при включенном хранителе
  НЕ будет включать лоты в отключенных плагину категориях. Для остальных категорий
  оно работает как раньше.
- Если хранитель **выключен**, а autoRestore у Кардинала **включен** — отключенные лоты
  могут быть восстановлены Кардиналом (плагин предупредит об этом в меню).
- Валютные подкатегории (биржа/«чипы») не обрабатываются — только обычные лоты.
- Между сохранениями лотов плагин делает паузу ~0.8 сек. (анти-флуд FunPay).
  Отключение категории с сотнями лотов может занять несколько минут — процесс идёт
  в фоновом потоке, по завершении придёт сообщение.
- При удалении плагина через ПУ хранитель останавливается, а перехват
  автовосстановления снимается.
